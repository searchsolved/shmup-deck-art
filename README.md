# Shmup Deck art

The flyer images shown by [Shmup Deck](https://github.com/searchsolved/shmup-deck),
one per game, cut to the card and scaled to at most 640 pixels wide as WebP.
`manifest.json` records each file's size and the scan it was made from.

These are scans of the original arcade sales flyers, collected from public
archives (libretro-thumbnails, LaunchBox, The Arcade Flyer Archive,
arcadeartwork.org, Wikipedia and archive.org). All artwork belongs to its
respective copyright holders and is mirrored here only so the deck can load
quickly. If you hold the rights to any of it and want it taken down, open an
issue and it will be removed.

Files are generated by `tools/build_art_mirror.py` in the Shmup Deck repo;
edits should be made there, not here.
